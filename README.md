呢份指南**唔隸屬於** Rockstar Games 或 Take-Two Interactive。《Grand Theft Auto》同相關名稱屬於其權利人。本倉庫只係把已引用嘅推出期媒體內容整理成可離線瀏覽嘅靜態網頁。

線上版（GitHub Pages）：<https://ai-k-gh.github.io/gta6-guide/>

## 點用

用任何現代瀏覽器打開 `index.html`，或瀏覽上面嘅 Pages 網址。建議用手機直向閱讀。

- 用「主題」切換：搵錢、實用技巧、隱藏內容、地圖資源、查證與限制。
- 「搵錢」可再按章節進度篩選；「隱藏內容」可再按任務／武器／收集品／觀賞彩蛋篩選。
- 搜尋框會在目前已選主題裏過濾正文（清空搜尋即返回完整分類）。
- 含位置或任務流程嘅段落用「預設收埋」摺疊，要自己點開。
- 「標記」只儲存在**呢個瀏覽器**（`localStorage`），唔會同步遊戲存檔，亦唔會上傳到伺服器。清除網站資料就會消失。
- 互動地圖按鈕會開啟外部網站 [oplay.cc/gta6/map](https://oplay.cc/gta6/map)，本站冇嵌入或複製其地圖資料。

無需登入、無需後端。
